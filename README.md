# Quiz App

A timed frontend quiz app covering HTML, CSS, JavaScript, and React.

## Features

- 10 questions shuffled randomly on each attempt
- 15-second countdown timer per question (auto-advances on timeout)
- Timer color changes: green → orange → red
- Progress bar showing quiz completion
- Category badge per question
- Score screen with per-question answer review
- Play again button

## Tech Stack

- React 18
- Vite
- CSS-in-JS (inline styles)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
